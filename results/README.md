# Published results

| Path | Content |
|---|---|
| `units/*.parquet` | 360 experiment units: 300 imputed units (dataset × mechanism × rate × seed, one row per imputer and model) and 60 complete-data retrain units (noise floor). 1,140 result rows in total. |
| `environment.json` | Python and library versions used to produce the units |
| `tables/` | Tables and test statistics generated by `analysis/analyze.py` (CSV and LaTeX) |
| `tables/facts.json` | Every summary number quoted in the article |
| `figures/` | Figures generated by `analysis/analyze.py` (PDF and PNG) |

Regenerate `tables/` and `figures/` from the units:

```bash
python analysis/analyze.py
```

Columns of each unit row: `dataset, model, mechanism, rate, seed, imputer, achieved_rate_train,
achieved_rate_test, nrmse, macro_f1, balanced_accuracy, ref_macro_f1, pr_auc, mcc, global_tau,
mean_class_tau, min_class_tau, delta_tau, global_top_k, mean_class_top_k, min_class_top_k,
model_only_global_tau, model_only_mean_class_tau, class_tau, class_top_k, class_recall, runtime_s`.
`class_tau`, `class_top_k` and `class_recall` are JSON lists with one value per class in label order.
Rows with `imputer = clean_retrain` compare a second complete-data model (seed + 1000) with the reference.
